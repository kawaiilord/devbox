# Noto Sans SC

`NotoSansSC.ttf` is the unmodified variable font `NotoSansSC[wght].ttf`
from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc).
It is bundled under the SIL Open Font License 1.1; see `OFL.txt`.

The existing Chinese fallback family now resolves to this local asset, so the
account and viewing UI do not depend on Google's fallback font service.
The official HTML homepage continues to use system fonts.
