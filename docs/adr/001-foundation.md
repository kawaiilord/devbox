# ADR-001：M1 基础版本

状态：基础实现采用；生产化调整通过后续 ADR 管理。

## 决策

- FastAPI 与 SQLAlchemy 处理业务事务；SQLite 用于本地开发，PostgreSQL 用于兼容性验证。
- 用户端为 React / TypeScript，管理后台有独立页面与服务端权限检查。
- 角色只有一个 universe_id，迁移使用版本条件 UPDATE，归属与幂等记录在同一事务写入。
- 共享事件有一份权威事实；观察与记忆独立，个人宇宙查询检查 owner_id。
- 模型域名解析后连接已校验的公网 IP，保留 Host 和 TLS SNI，禁止自动重定向。
- Agent 的能力列表明确标注已接入与计划功能。当前只进行任务内文件操作。
- 文件版本追加保存。JSON/Python 分别做格式或语法检查，不声称运行了生成程序。
- HTML 下载使用附件响应，预览处于无同源权限且限制网络的 iframe。

## 阶段限制

M1 使用单进程开发 Worker；多实例队列、Outbox、完整 Saga、正式数据库迁移仍需后续开发。
世界活动为规则驱动，模型只在配置后参与聊天或任务。
记忆当前按范围和时间读取，尚无向量检索、自动事实提取或时间合并。
聊天当前为完整响应，音视频与流式输出未接入。
后台目前为 user/admin 两级权限；更多角色、MFA 和完整成本账本尚未交付。
认证限流当前为进程内实现，生产环境需要集中限流和可信代理配置。
