# 媒体源订阅与影视播放

管理入口：管理控制台 → 媒体订阅。观影入口：影视发现 → 片源片库，或影视搜索 → 片源搜索。

## 导入和更新

1. 点击“导入订阅 / 文件”，填写名称和订阅地址，或上传 / 粘贴配置。
2. 查看新增、更新、移除、重复和不兼容条目，确认后应用。
3. 网络订阅可设置每 1–168 小时更新，默认 24 小时。调度器每分钟检查到期任务。
4. “检查更新并预览”可以在手动更新前检查差异；定期更新自动应用兼容结果，并保留更新记录。
5. 接口获取失败、格式无效或结果为空时保留上一次配置，不会清空片库。

标准 JSON 示例（地址为占位符，替换后使用）：

```json
{
  "sources": [
    {"name": "我的影视接口", "type": "cms", "url": "https://example.com/api.php/provide/vod/"},
    {"name": "我的频道", "type": "m3u", "url": "https://example.com/channels.m3u"}
  ]
}
```

也接受同样条目的 JSON 数组、`api_site` 对象，以及 TVBOX 配置中的 `sites` 和带 `url` 的 `lives` 条目。

- 影视接口使用兼容 AppleCMS 的 JSON 响应（`vod_id`、`vod_name`、`vod_play_from`、`vod_play_url` 等）。支持 `ac=detail`、`wd`、`pg`、`ids`。
- TVBOX `type: 1` 标准接口，以及指向 `/provide/vod` 且返回兼容 JSON 的 `type: 0` 接口可以导入。
- M3U 使用 UTF-8 `#EXTM3U` / `#EXTINF` 频道列表，支持频道名称、`group-title`、`tvg-id` 和 HTTP(S) 地址。
- 视频自己的 HLS 分片清单不是频道订阅，导入时会提示。
- 不执行爬虫、JAR、JS、Python、私有解析规则，不支持 XML 影视接口、DRM 解锁及需要专用请求头的源。跳过的类型会显示在预览中。
- 同一个接口会在目录中去重，但保留订阅归属；删除一份订阅不会删除其他订阅仍引用的片源。

每份输入最多 2 MB；全站最多 24 份订阅、64 个独立片源；每次最多读取 8 个 M3U 列表，每个最多 2000 个频道；加密配置总量最多 8 MB。导入预览有效期 10 分钟，重启后需重新生成；多节点部署时预览和确认需落在同一节点。

## 搜索与播放

- 登录后逐源检索，结果陆续显示；单个接口失败不会阻止其他结果。
- 标题、年份、类型一致的作品合并为同片来源；缺少年份的不同接口结果保守地分开显示，避免混入翻拍或不同季。
- 海报打开后可选来源、线路、剧集，创建房间或加入已参加且有片单权限的房间。
- “全部剧集”一次保存到片单；每个房间最多 500 集，同集最多 8 条备用线路。只按对应剧集名称 / 集数匹配，不按列表位置盲目换源。
- 保留原有建房审核、房间权限、切集和自动连播规则。需要审批时显示申请状态。
- 媒体经过短期播放票据代理；HLS 分片和密钥也受房间权限与片源启停状态约束。订阅链接、接口参数、原始播放地址不出现在普通用户的目录结果中。
- 播放异常先重试两次；仍失败时只有房主触发房间统一换源，保留当前剧集、播放位置、暂停/播放状态。其他成员跟随房间状态。
- 画质可通过供应方提供的线路及原有播放器能力选择；系统不凭空生成供应方没有提供的清晰度或可播放版权内容。

后台支持批量连接检测和启停。接口连续失败三次进入 5 分钟冷却，冷却后搜索可重试，管理员也可以主动检测恢复。延迟显示最近一次检测 / 查询耗时，命中短期缓存的查询可能很快。

## 持久化与回滚

订阅、禁用状态、健康状态及最近 40 次更新结果保存在加密的版本化配置中，管理操作进入审计日志。定期更新采用数据库 CAS 和任务租约，避免多节点重复提交或覆盖管理员的同时修改。

022 迁移只扩展媒体类型，个人播放绑定继续使用现有媒体源、播放票据和房间表。常规回滚保留数据库新增数据。019 迁移的兼容修复基线 `9c18aa3` 已单独构建，用于回滚镜像；不要直接运行会重建旧类型约束的原始旧二进制。

真实订阅由站点管理员稍后导入；本轮开发只使用隔离演示源验收，不向生产片库添加测试作品。
