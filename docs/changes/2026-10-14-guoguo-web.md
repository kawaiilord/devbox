# 果果短剧：网页版独立功能板块

状态：开发与验证中，尚未发布；以完成后的发布记录为准。

## 基线与范围

- 代码基线：`2c8fccc`，生产后端 `338cd82`。
- 用户明确要求：在导航中紧接“影视发现”增加同级“果果短剧”功能板块；先完成网页端，手机及其他端的专门适配最后处理。
- 不改变官网入口、注册策略、现有媒体订阅、会员积分、公开房间访问规则。

## 新增

- 独立黑白主题短剧页：真人剧、漫剧、AI 剧、热播榜、搜索、海报、分页及失败重试。
- 果果数据适配服务：基于用户上传源码，独立服务令牌，仅开放必需接口；未迁移上传项目的账号配置、剧库缓存、历史及任务。
- 后端鉴权短剧 API，稳定剧/集 ID，复用现有目录详情、房间片单及媒体票据。
- 相同剧集的转码与清单供多个房间观众复用；海报及 HLS 地址通过同帧代理，不向前端公开内部服务地址、令牌或上游媒体密钥。
- 自动验证鉴权、私网边界、跨域重定向拒绝、分集身份、多人共享真实合成 HLS、网页切换与异步分类竞态。

## 修改

- 桌面导航顺序：观影大厅 → 影视发现 → 果果短剧 → 发现房间。
- 现有选集组件支持直接打开指定短剧，选择当前集或整剧后建房/加入已参加房间。
- 仅受服务端固定配置约束的短剧绑定允许访问指定私有适配服务；普通订阅仍禁止本机/内网地址。

## 移除

无既有产品功能移除。果果独立程序原来的管理、下载、全局观看历史、设置及导出接口不对外挂载。
