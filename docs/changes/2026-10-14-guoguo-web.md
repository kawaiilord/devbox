## 新增

- 独立黑白主题短剧页：真人剧、漫剧、AI 剧、热播榜、搜索、海报、分页及失败重试。

- 后端鉴权短剧 API，稳定剧/集 ID，复用现有目录详情、房间片单及媒体票据。
- 独立个人播放票据，不创建房间或成员；切集、暂停、进度、倍速、全屏与到期续签。
- 当前账号的可用自建房间列表；选择已有房间时原子追加片单、选择当前集并带入播放位置。
- 相同剧集的转码与清单供多个房间观众复用；海报及 HLS 地址通过同帧代理，不向前端公开内部服务地址、令牌或上游媒体密钥。
- 自动验证鉴权、私网边界、跨域重定向拒绝、分集身份、多人共享真实合成 HLS、网页切换与异步分类竞态。

## 修改

- 桌面导航顺序：观影大厅 → 影视发现 → 果果短剧 → 发现房间。
- 电影与短剧共用直接播放组件，点开影片即可单人观看；仅在点击相应按钮时创建房间或进入本人已有房间。
- 仅受服务端固定配置约束的短剧绑定允许访问指定私有适配服务；普通订阅仍禁止本机/内网地址。

## 移除

移除“必须创建房间才能观看”的交互，以及播放页手工填写房间码的加入入口，替换为单人播放器和自建房间选择。果果独立程序原来的管理、下载、全局观看历史、设置及导出接口不对外挂载。
